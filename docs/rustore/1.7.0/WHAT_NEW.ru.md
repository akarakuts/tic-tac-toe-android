## GitHub Release

### Крестики-нолики Android 1.7.0 (versionCode 19)

Главное в этом релизе — **мультиплеер по Bluetooth** (MVP): хост/гость, рукопожатие config/ack, синхронизация ходов и экран партии на двух устройствах. Разрешение `BLUETOOTH_SCAN` с `neverForLocation` — без доступа к геолокации.

**Мультиплеер**
- Вкладка «Мультиплеер»: создать партию / присоединиться / отмена
- RFCOMM-транспорт, JSON-протокол (config, ack, move, new_game)
- Синхронизация ходов и обработка разрыва связи

**Игровой опыт** (накоплено с v1.2.0)
- ИИ «Эксперт», тема «Океан», режим серии best-of-N
- 7 локальных достижений, шаринг результата, виджет домашнего экрана
- Отмена хода, подсказка, онбординг, язык (System/EN/RU), громкость звука
- Статистика двух игроков, векторные фигуры, анимация линии победы и конфетти

**Качество и стабильность**
- Исправление краша: `MultiplayerViewModel` с конструктором `Application` для стандартной `viewModel()` factory
- Рефакторинг: `StatusTextResolver`, `AiCoordinator`, `SoundPlayer`
- ~82 юнит-теста, detekt, R8 keep-rules для multiplayer
- Документация: ARCHITECTURE, MULTIPLAYER_PROTOCOL, CONTRIBUTING, privacy (Bluetooth)
